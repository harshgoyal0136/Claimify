## Contracts

```python
@dataclass
class Signal:
    name: str
    score: float | None      # 0 authentic … 1 manipulated; None if abstained / n.a.
    confidence: float        # 0..1
    reason: str              # one sentence an adjuster understands
    evidence: dict           # heatmap path, manifest json, diff rows, boxes …
    abstained: bool = False  # quality gate fired
    applicable: bool = True  # False → "not applicable: PNG has no JPEG tables"
    tier: Literal["fast", "deep", "doc", "identity", "claim"] = "fast"

@dataclass
class Region:
    box: tuple[int, int, int, int]
    area_frac: float
    signals: dict[str, float]    # which signals fired inside the box
    reason: str                  # "Region A (bumper, 12%): localizer anomaly 0.91, …"
    stage: int                   # 1 = fast, 2 = AE-corroborated

@dataclass
class ClaimScore:
    image_score: float | None
    document_score: float | None
    identity_score: float | None
    overall: float
    band: Literal["LOW", "MEDIUM", "HIGH", "UNCERTAIN"]
    waterfall: list[tuple[str, float]]
    regions: list[Region]
    signals: list[Signal]
    pending_deep: bool           # True until the deep tier lands; UI shows "deep scan running"
```

## Image lane

### I0 Preprocess (< 0.5 s, HEIC decode budgeted separately ≈1–2 s in its own thread)
- HEIC/WebP/PNG/JPEG → RGB. Long side ≤ 1024 for learned models; original bytes kept
  only for C2PA / EXIF / JPEG-table checks.
- Quality gate: min side < 256, est. JPEG quality < 40, or Laplacian variance below
  threshold → `quality_flag`; caps fast-tier confidences; composite may return UNCERTAIN.
- Every intermediate cached by sha256 of original bytes.

### Fast tier — ThreadPoolExecutor in one process (measure vs processes once; keep winner)
Card emission order: forensics → CLIP probe → localizer. First card ≤ 2 s p95.

**I4 Forensics** (all CPU, ≈1 s)
| Check | Says |
|---|---|
| C2PA (`c2pa-python`) | "Content Credentials: generated by Adobe Firefly" / "signed by Photoshop, actions: …". Verify signature. Absence is neutral (Midjourney doesn't sign). |
| EXIF | Software tag; Make/Model absent at phone resolution; DateTimeOriginal vs file time. Missing EXIF = weak (WhatsApp strips). |
| JPEG q-tables | Non-standard tables; double-compression periodicity. `applicable=False` on PNG/HEIC. |
| Copy-move (SIFT + RANSAC) | Draws matched region pairs. Moves to deep tier if the bench fails. |
| Noise residual | Block variance outliers → splice cue; also feeds the fallback localizer. |

**I2 CLIP probe** — `open_clip` ViT-L/14 frozen; logistic head trained on
`heldout=0`; 224 px by default (336 only if bench allows). Pre-committed rule: if
held-out Flux AUC < 0.80 in pre-build, add a DINOv2 ViT-B head and keep the winner.

**I3 Localizer — interface, two implementations, config-switched**
```python
class Localizer(Protocol):
    def __call__(self, img) -> LocResult: ...   # heatmap, reliability, integrity
```
- `trufor`: vendored weights, 768 px cap (512 if bench fails). Non-commercial licence →
  stated on the slide as "swappable; TruFor for the prototype".
- `fallback`: a permissive-licence model if the licence check (done weeks ahead on
  MVSS-Net / PSCC-Net / CAT-Net) passes; otherwise **our union localizer** = mini-AE at
  256 px (≈2 s CPU) error map ∪ noise-residual blocks. Reliability = agreement of the two.
- One full rehearsal runs on `fallback`.

**I5 Family map** — hierarchical softmax on CLIP features over
`root → {real, diffusion → {sd15, sdxl, flux*, firefly, midjourney, nova}, edited → {splice, copymove, inpaint}}`
(*held out). Open-set: max leaf prob < 0.60 → "unknown family". Rendered as a radial
tree (Plotly sunburst). Reason: "diffusion branch, nearest SDXL (0.81)". On Flux, mass
lands on the diffusion node — that is the demo line. No hyperbolic geometry anywhere.

**Regions stage 1** — localizer heatmap (reliability-masked) → connected components →
boxes ≥ 0.5 % area → per-box reason from which fast signals fired inside. Boxes with a
single weak signal are not shown.

### Deep tier — async, `pending_deep=True` until it lands (≤ 30 s CPU)
**I1 AE reconstruction (AEROBLADE)** — `diffusers.AutoencoderKL`, 384–512 px, LPIPS
VGG layer 2, min over VAEs. CPU → 1 VAE (SD1.5). GPU present → SD1.5 + SDXL + Flux VAE.
Always on, weight ≈0.20 of the image lane, confidence cap 0.7. Card text: "Reconstruction
test: <low|high> error. Most informative for diffusion-generated images; supporting
evidence." Per-patch error map → **Regions stage 2**: existing boxes re-scored with AE
evidence appended; new low-error patches may add boxes.

## Document lane
- **D0** `pikepdf`/`pypdf`: count xref sections; if > 1, truncate at the earlier
  `startxref`, re-parse, extract text from both revisions, diff line items/totals →
  **version diff table**. Producer vs Creator mismatch; CreationDate vs ModDate delta;
  embedded fonts per page, rogue font on few glyphs (esp. digits).
  *Variant B: timebox 3 h; fallback is the metadata story without the diff.*
- **D1** Render 200 dpi, `pytesseract --psm 6`, `image_to_data` for per-word confidence;
  single-digit confidence dips flagged.
- **D2** Doc-type classify (keyword rules first, LLM-JSON only if ambiguous) →
  template. **Invoice**: items sum to subtotal, tax rate ∈ set, total, dates ordered,
  invoice-number format. **Medical**: visit ≤ report ≤ claim date, provider/registration
  format, ICD-10 code pattern, billed totals if present. **ID**: MRZ/format checks if
  cheap. LLM extracts to a fixed JSON schema; all checks are code.
- **D3** Scans: fast tier on the scan image (copy-move, noise residual, localizer) + D1–D2.

## Identity lane
InsightFace `buffalo_l`; ArcFace cosine, threshold from `thresholds.yaml`; fast tier on
the selfie. No morph heuristic.

## Claim-level checks (exactly three)
1. Invoice date earlier than earliest photo DateTimeOriginal.
2. Two photos in one claim from different camera Make/Model.
3. Claimant name on ID ≠ name on invoice (RapidFuzz < 85).

## Scorer
- Per-lane weighted mean of applicable, non-abstained signals; weights × confidence.
- `overall = 0.5*max(lanes) + 0.5*mean(lanes) + claim_bonus`.
- Bands LOW < 0.35 ≤ MEDIUM < 0.65 ≤ HIGH; UNCERTAIN if quality gate fired and no
  strong deterministic evidence (C2PA, PDF diff).
- Waterfall sorted by |contribution|. Recomputed when the deep tier lands; UI animates.
- Calibrate on `calib` only; report on held-out. No gates, no ablations.

## Narrative
Template renders instantly from waterfall + reasons (PII placeholders). Bedrock Claude
(Qwen fallback) is called in the background; if it returns within 4 s the prose is
swapped in. The score screen never waits.

## UI (Streamlit, single process)
- **Images**: original | heatmap overlay | AE error map (when ready); Regions list;
  signal cards (grey for n.a./abstained with reason); family map.
- **Documents**: page render with OCR boxes; version diff table; metadata card; flags.
- **Score**: gauge, band, waterfall, narrative, accept / reject+note / escalate.
- **Arena**: upload or seed → attack (inpaint | recompress q70) → re-score; held-out
  table; robustness row.
Audit: SQLite (case_id, sha256, scores JSON, band, reviewer, action, note, ts).

## Arena
Two live attacks: Nova Canvas `INPAINTING` (maskPrompt) and JPEG recompress q70.
Fallback chain: Bedrock → local SD1.5 inpaint at 384 px on CPU (measured; 15 steps if
> 60 s) → pre-generated attack with one honest sentence. Held-out table computed
offline; includes SD1.5, SDXL, Nova, Flux columns so the hard attacks are visible.

## Decisions
| Decision | Reason |
|---|---|
| Two-tier image lane | Perceived latency is the first card; AE is the slow signal and must not block. |
| No GAN gate, no GAN branch | Dead code with zero training images; weights already handle it; blind spot is published as an eval-only GAN row instead. |
| Hierarchical softmax, not hyperbolic | Same visual, honest label, unseen-generator beat falls out of the math. |
| Localizer interface | TruFor licence is non-commercial; swappable is the deployability answer. |
| Template narrative first | Reproducibility is 25 % of the score; the LLM is nondeterministic and slow. |
| No video / agents / physics rules / feedback beat | Zero rubric points, real hours, credibility risk. Stated as decisions on the slide. |
| Streamlit single process | One failure surface. FastAPI only if already built (Variant A). |
