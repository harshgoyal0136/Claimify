CLAIMSHIELD — PHASE BY PHASE EXECUTION
======================================
Derived from FINAL_APPROACH (wins on conflict), PREBUILD, SCHEDULE_24H, LATENCY, EVAL, DEMO.
This file adds ordering, gates and repo state. It adds no components.

Repo state at plan time: docs + configs + scripts/bench.py + scripts/smoke_bedrock.py
+ scripts/hpc/generate.sbatch. No claimshield/ package, no tests, no data, no git.

Ordering principle: long-lead items first (organiser ruling, licences, weights, HPC queue),
then a WALKING SKELETON that makes `make bench` and the UI run end-to-end on a trivial
pipeline, then widen signal by signal. Each signal lands with a test, a bench run and a
card in the UI.

PHASE 3 — WALKING SKELETON  (~0.5 day) — THE MOST IMPORTANT PHASE
-----------------------------------------------------------------
Goal: the whole shape runs end-to-end on CPU before any real model is added.

3.1  claimshield/contracts.py: Signal, Region, ClaimScore exactly as ARCHITECTURE.md.
     Done when: imported everywhere; no bare floats.
3.2  claimshield/preprocess.py: HEIC/WebP/PNG/JPEG -> RGB, long side <= 1024, quality
     gate from thresholds.yaml, sha256 cache.
     Done when: test — tiny/blurry image sets quality_flag.
3.3  One real signal: signals/forensics/exif.py, applicable=False on PNG.
     Done when: test passes.
3.4  scoring/composite.py: per-lane weighted mean (weights x confidence, skip n.a. /
     abstained), overall = 0.5*max + 0.5*mean + claim_bonus, bands, UNCERTAIN rule,
     waterfall.
     Done when: tests for band edges, UNCERTAIN with/without strong evidence, n.a. excluded.
3.5  claimshield/pipeline.py: score_image(path, on_card, wait_deep) with
     ThreadPoolExecutor, card order from runtime.yaml, returns t_fast / t_deep.
     Done when: bench.py imports and runs.
3.6  ui/app.py: upload -> cards stream into placeholders -> score. Grey cards for
     n.a./abstained. Uploads in a temp dir, wiped after scoring.
     Done when: upload a photo, see a card and a band.
3.7  make bench on the three files. (bench clears the sha256 caches between runs; no nonce bytes, see ISSUES #16.)
     Done when: reports/latency_latest.md written.

GATE 3: pytest -q green, make bench report exists, UI runs. Commit v0.1.


PHASE 4 — IMAGE LANE, FAST TIER (P2 part 1)  (~1 day)
-----------------------------------------------------
Rule: every signal = one file + one test + re-run make bench.
Card emission order: forensics -> CLIP -> localizer.

4.1  Forensics: c2pa.py (verify signature; absence neutral), jpeg_qtables.py (n.a. on
     PNG/HEIC), copy_move.py (SIFT + RANSAC, draws pairs), noise_residual.py.
     Done when: each has a test incl. wrong-file-type n.a.
4.2  clip_probe.py: 224 px, logistic head trained on heldout=0, pickled, features cached.
     RULE: held-out Flux AUC < 0.80 -> add dino_probe.py, keep the winner.
     Done when: held-out AUC recorded.
4.3  localizer/base.py (Protocol), trufor.py (768 px), fallback.py (per 1.1: permissive
     model, or mini-AE 256 px + noise-residual union). Config flag localizer.impl.
     Done when: both produce heatmaps on CPU; test covers both.
4.4  family_map.py: hierarchical softmax on CLIP feats, tree per FINAL_APPROACH s.1
     (no GAN leaf), open-set rule max-prob < 0.60 -> unknown, sunburst JSON.
     Done when: Flux mass lands on the diffusion node.
4.5  regions.py stage 1: reliability-masked heatmap -> components -> boxes >= 0.5 % area
     -> per-box reason; hide single-weak-signal boxes.
     Done when: region reason strings on an inpaint sample.
4.6  make bench. Apply LATENCY.md escalations in order if over spec.
     Threads vs processes -> runtime.yaml.
     Done when: first card p95 <= 2 s, composite p95 <= 8 s.

GATE 4: spec met on the demo laptop with BOTH localizer impls. Commit v0.3.

TOP RISKS
---------
- No written ruling before the event  -> plan for Variant B; pre-build only P0/P1.
- TruFor weights/licence unavailable  -> fallback localizer is first-class (4.3),
                                         rehearsed in 11.2.
- insightface / Tesseract / Poppler install pain on Windows -> done in 0.4, day 0.
- HPC queue delays                    -> submit in Phase 1; Nova + manual Firefly give a
                                         minimum viable fake set.
- Held-out Flux AUC < 0.80            -> pre-committed DINOv2 swap (4.2).
- CPU bench over spec                 -> LATENCY.md escalations in order; kill-switch at 10 s.
